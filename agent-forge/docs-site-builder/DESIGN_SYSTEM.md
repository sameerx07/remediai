# Design System — Modern Docs

This document defines the visual language every site generated by `docs-site-builder` uses. It is **not** a stock Docusaurus theme. Every element is deliberately designed to feel more current than Stripe, Vercel, Tailwind, and Linear docs.

---

## 1. Design Principles

1. **Content is the hero.** Chrome recedes, typography leads.
2. **Motion has meaning.** Every animation communicates state or hierarchy — never decoration for its own sake.
3. **Depth through light, not shadow.** Gradients, glow, and glassmorphism instead of heavy drop shadows.
4. **Dark mode is a first-class citizen.** Not just inverted colors — a separately designed palette with proper contrast, warmer surfaces, and reduced blue light.
5. **Respect the reader.** Reduced motion, high contrast, and keyboard-first navigation are defaults, not afterthoughts.

## 2. Typography

### Font stack

```css
/* Body */
font-family: 'Inter Variable', 'Inter', -apple-system, BlinkMacSystemFont,
             'Segoe UI', Roboto, sans-serif;

/* Code */
font-family: 'JetBrains Mono Variable', 'JetBrains Mono',
             'SF Mono', Menlo, Consolas, monospace;

/* Display (hero, H1) */
font-family: 'Inter Variable', 'Inter', sans-serif;
font-feature-settings: 'ss01', 'ss02', 'cv11';   /* alt one, alt L, tabular figures */
letter-spacing: -0.03em;                          /* tight for display sizes */
```

Both fonts are **self-hosted** as WOFF2 variable fonts. No Google Fonts network calls.

### Scale

| Element | Size (rem) | Line height | Weight | Letter spacing |
|---|---|---|---|---|
| Display / Hero H1 | 4.5 | 1.05 | 800 | -0.04em |
| Page H1 | 2.75 | 1.15 | 700 | -0.03em |
| H2 | 2.0 | 1.25 | 700 | -0.02em |
| H3 | 1.5 | 1.35 | 600 | -0.015em |
| H4 | 1.15 | 1.4 | 600 | -0.01em |
| Body | 1.0 | 1.7 | 400 | 0 |
| Small | 0.875 | 1.6 | 400 | 0.005em |
| Code inline | 0.9em | inherit | 500 | 0 |
| Code block | 0.9 | 1.65 | 400 | 0 |

Long-form paragraph max-width: **68ch**. Headings can span the full column.

## 3. Color System

### Structure

Every theme provides **11 shades per hue** (50 → 950) so gradients, borders, and hover states stay in harmony.

```css
--brand-50   /* backgrounds */
--brand-100
--brand-200  /* subtle borders */
--brand-300
--brand-400  /* icons on light */
--brand-500  /* primary buttons, links */
--brand-600  /* button hover, active nav */
--brand-700  /* text on light bg */
--brand-800
--brand-900
--brand-950  /* text on dark bg */
```

### Aurora preset (default)

| Token | Light | Dark |
|---|---|---|
| `--surface-0` (page bg) | `#fdfcff` | `#0a0611` |
| `--surface-1` (card bg) | `#ffffff` | `#12091f` |
| `--surface-2` (raised) | `#f7f5fb` | `#1a0f2e` |
| `--text-primary` | `#0f0a1f` | `#f5f0ff` |
| `--text-secondary` | `#4b4360` | `#a89cc0` |
| `--text-tertiary` | `#7c7295` | `#6b5f85` |
| `--border-subtle` | `#ece7f5` | `#241735` |
| `--border-strong` | `#d8cfe8` | `#3a2856` |
| `--brand-primary` | `#a855f7` | `#c084fc` |
| `--brand-accent` | `#ec4899` | `#f472b6` |
| `--brand-gradient` | `linear-gradient(135deg, #a855f7 0%, #ec4899 100%)` | same |

Dark mode uses **true black-toned violet** (`#0a0611`), not gray. This reduces eye strain and makes gradients pop.

### Contrast

All text-on-background pairs meet **WCAG AA (4.5:1)** minimum. Interactive elements meet **AA large (3:1)** or higher.

## 5. Navigation

### Top navbar

- **Height:** 64px

- **Effect:** `backdrop-filter: blur(20px) saturate(180%)`

- Width: 260px
- Background: transparent, blends with page
- Section headers: uppercase, `letter-spacing: 0.06em`, `--text-tertiary`, 11px
- Links: 14px, `--text-secondary`, 6px vertical padding
- Active link: gradient dot on left (4px × 4px), text becomes `--text-primary`, weight 600
- Collapsible groups: chevron rotates 90° on open, all transitions 200ms cubic-bezier(0.16, 1, 0.3, 1)

### TOC (right)

- Width: 220px, sticky
- Active heading: gradient vertical bar (2px wide) with glow shadow

## 6. Hero Section (Landing Page)

The signature element. Never seen this on Vercel or Stripe.

### Structure

```jsx
<Hero>
  <AuroraBackground />       {/* animated conic + radial gradients */}
  <GridOverlay />             {/* subtle 40px CSS grid, mask-image fade to center */}
  <Eyebrow />                 {/* small pill above headline */}
  <Headline />                {/* 4.5rem, gradient text */}
  <Subheadline />             {/* 1.25rem, max 60ch, secondary color */}
  <CTAGroup>
    <PrimaryCTA />            {/* gradient button */}
    <SecondaryCTA />          {/* glass button */}
  </CTAGroup>
  <ScrollHint />              {/* animated chevron */}
</Hero>
```

### Aurora background

Three overlapping animated gradient blobs:

```css

  height: 55vw;
  border-radius: 50%;

}
.aurora::before {
  top: -20%; left: -10%;
  background: conic-gradient(from 90deg, #a855f7, #ec4899, #a855f7);
}
.aurora::after {
  bottom: -25%; right: -15%;
  background: conic-gradient(from 210deg, #ec4899, #8b5cf6, #ec4899);
  animation-delay: -8s;
}
.aurora > span {
  top: 30%; left: 40%;
  background: radial-gradient(circle, #f472b6 0%, transparent 60%);
  animation-delay: -14s;
}
@keyframes drift {
  0%   { transform: translate(0, 0) rotate(0deg) scale(1); }
  100% { transform: translate(6vw, -4vh) rotate(35deg) scale(1.15); }
}
```

### Gradient text headline


## 7. Section Cards

Used on the landing page and any `<CardGrid>` component in Markdown.

### Anatomy

- **Padding:** 32px
- **Border radius:** 16px
- **Border:** 1px solid `--border-subtle`
- **Background:** `--surface-1`
- **Number badge:** top-left, 12px monospaced, gradient text
- **Icon:** top-right, 24px, `--brand-primary`, opacity 0.6
- **Title:** H3 scale, gradient text on hover
- **Description:** 14px, `--text-secondary`
- **Bottom:** subtle chevron that translates 4px right on hover

### Hover interaction

```css
.card {
  position: relative;
  transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1),
              border-color 0.3s ease;
  will-change: transform;
}
.card::before {
  /* Gradient border on hover */
  content: '';
  position: absolute;
  inset: -1px;
  border-radius: inherit;
  background: var(--brand-gradient);
  opacity: 0;
  z-index: -1;
  transition: opacity 0.3s ease;
}
.card::after {
  /* Radial glow that follows cursor */
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  background: radial-gradient(
    600px circle at var(--mx, 50%) var(--my, 50%),
    rgba(168, 85, 247, 0.08),
    transparent 40%
  );
  opacity: 0;
  transition: opacity 0.4s ease;
  pointer-events: none;
}
.card:hover {
  transform: translateY(-4px);
}
.card:hover::before,
.card:hover::after {
  opacity: 1;
}
```

The card tracks the cursor via a tiny JS listener that sets `--mx` and `--my` custom properties. This creates the Linear-style spotlight glow.

## 8. Code Blocks

### Container

- Background: `#f8f6fd` light / `#0d071a` dark
- Border: 1px solid `--border-subtle`
- Border radius: 12px
- Padding: 20px 24px
- Font size: 14px
- Line height: 1.65
- Overflow-x: auto with custom scrollbar

### Header row

- Language icon (24px SVG) + language label
- Filename (if provided) in center
- Copy button on right (icon-only, tooltip on hover)

### Syntax highlighting

Custom Prism theme derived from GitHub Dark, adjusted for the Aurora palette. Key changes from default:

- Keywords: `--brand-primary` (violet)
- Strings: `#10b981` (emerald)
- Numbers: `#f59e0b` (amber)
- Comments: `--text-tertiary` italic
- Punctuation: `--text-secondary`

### Copy button

```jsx
<button className="copy-btn" onClick={copy}>
  {copied ? <CheckIcon /> : <CopyIcon />}
  <span className="sr-only">Copy code</span>
</button>
```

Success state shows a green check for 1.5s.

### Line highlighting

Support `{2,4-6}` syntax for highlighting lines. Highlighted lines get a subtle gradient background from left edge and a 2px gradient left border.

## 13. Scroll Progress Indicator

Thin 2px bar fixed to top of viewport (above navbar).

```css

  position: fixed;
  top: 0; left: 0;
```

## 14. Motion

### Timing tokens

| Token | Duration | Easing |
|---|---|---|
| `--ease-quick` | 150ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| `--ease-smooth` | 250ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| `--ease-slow` | 500ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| `--ease-bounce` | 400ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` |

### On-scroll animations

Section cards fade + slide up 12px when they enter the viewport (`IntersectionObserver`, only fires once per element).

### Reduced motion

All non-essential animations disabled when `prefers-reduced-motion: reduce`:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
  .aurora { animation: none; }
}
```

## 15. Dark Mode

Not just inverted colors. Every dark palette is designed separately:

- **Surfaces** use warm violet-tinted blacks (`#0a0611`), not neutral gray
- **Borders** are ~10% opacity of primary text color
- **Code blocks** get deeper, richer backgrounds to make syntax colors pop
- **Gradients** are unchanged — they read the same in both modes
- **Shadows** become brand-tinted glows: `0 0 60px rgba(168, 85, 247, 0.15)`

Toggle uses `prefers-color-scheme` on first visit, then respects user's manual choice (stored in `localStorage`).

Transition between modes: 300ms fade on `color` and `background-color` for `<html>` — no jarring flash.

## 16. Accessibility Checklist

The agent verifies every generated site meets these:

- [x] All interactive elements have `:focus-visible` styles (2px gradient outline)
- [x] Skip-to-content link at top of page
- [x] Semantic HTML (`<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`)
- [x] Landmarks properly labeled with `aria-label`
- [x] Heading hierarchy strict (no skipped levels)
- [x] Color contrast ≥ 4.5:1 for body text, ≥ 3:1 for large text and UI
- [x] `prefers-reduced-motion` honored
- [x] `prefers-color-scheme` honored on first visit
- [x] Keyboard navigation works everywhere (Tab, Shift+Tab, Enter, Escape, Arrow keys in menus)
- [x] Screen-reader-only text for icon-only buttons (`.sr-only` class)
- [x] Forms use proper `<label>` elements

## 17. Performance Budget

Every generated site targets:

- **First Contentful Paint:** < 1.2s
- **Largest Contentful Paint:** < 2.0s
- **Total Blocking Time:** < 100ms
- **Cumulative Layout Shift:** < 0.05
- **JS bundle (main):** < 180 KB gzipped
- **CSS:** < 40 KB gzipped

Achieved via:

- Self-hosted variable fonts (`font-display: swap`)
- Above-the-fold CSS inlined by Docusaurus
- Route-level code splitting (Docusaurus default)
- Images `<img loading="lazy" decoding="async">`
- No web fonts from Google
- No analytics scripts by default

---

## 18. Print Styles

`docs-site` includes a `@media print` stylesheet:

- Navbar and sidebars hidden
- Background gradients removed
- Links show their href after the text
- Code blocks retain background (grayscale)
- Page breaks between top-level headings

Used automatically when the user clicks the "Download PDF" button (which triggers `window.print()` → save as PDF).

Optionally, if the user enables `pdfExport: true`, the agent adds `md-to-pdf` and a `generate:pdf` npm script for a proper server-side PDF generator.
